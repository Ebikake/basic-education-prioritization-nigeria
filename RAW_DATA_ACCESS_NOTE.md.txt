# Raw Data Access Note

The primary project workbook used for this capstone project has been uploaded to the repository:

`data/raw/Capstone_Stage_ML1_Model_Ready_Dataset.xlsx`

This workbook contains the model-ready datasets and supporting sheets used to generate the interim cleaned datasets, processed datasets, model outputs, figures, and documentation included in the repository.

However, the original raw source files downloaded from external portals were **not uploaded** to the repository. These include the underlying UBEC, NBS, Budget Office, and DMO source reports or files from which the project workbook was prepared. They are retained locally as source evidence because some raw files may be large, externally hosted, or not required for reproducing the current interim analysis from the uploaded model-ready workbook.

The repository includes the reproducible project outputs derived from the uploaded workbook, including:

- interim cleaned datasets in `data/interim/`
- processed model-ready datasets in `data/processed/`
- reproducible notebooks in `notebooks/`
- model-output tables in `outputs/tables/`
- figures in `outputs/figures/`
- model results workbook in `outputs/model_results/`
- documentation in `docs/`

Therefore, the uploaded workbook and derived repository files are sufficient to reproduce the interim analysis and model validation reported in the capstone document. The external raw source reports should be consulted separately where full source-level audit verification is required.
